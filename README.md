# example-nextjs

A simple Next.js portfolio site used as a tutorial example for [DojOps](https://github.com/dojops/dojops).

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js 15 (static export)
- React 19
- TypeScript 5
- Tailwind CSS v4

## DojOps Tutorials

This project is intentionally basic — it's designed for DojOps to analyze and improve:

- **[Enhance a Next.js Project](https://docs.dojops.ai/tutorials/enhance-nextjs-project)** — Scan, check, and enhance the CI and Dockerfile
- **[Security Audit & Remediation](https://docs.dojops.ai/tutorials/security-audit)** — Run scans and auto-remediate findings
